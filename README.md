# Vision Coal Gangue

基于计算机视觉的煤块/矸石识别与分选实验项目。项目当前处于阶段性开发版本，已包含 YOLO 目标检测训练、单图推理、Intel RealSense D435i 点云体积估算实验，以及视觉端与上位机的通信协议草案。完整系统还包含用于机械臂控制、相机通信、任务决策和人工操作界面的上位机软件。

项目目标是先通过视觉模型对传送带上的煤块和矸石进行快速分类；当检测结果置信度低于设定阈值时，再调用双目深度相机估算目标体积，并结合重力传感器得到的质量计算密度，从而对低置信度目标进行二次判别。上位机负责接收视觉端识别结果，融合传感器信息，向机械臂下发抓取/分拣指令，并提供可视化监控与人工干预入口。

## 技术路线

```text
RGB 图像
  -> YOLO 目标检测
  -> 输出 bbox / class / confidence
  -> confidence >= 阈值：直接采用视觉分类结果
  -> confidence < 阈值：进入二次判别

D435i 深度图 + bbox/ROI
  -> 点云生成
  -> 底面平面拟合
  -> 物体点云提取
  -> 高度积分估算体积

重力传感器
  -> 读取质量
  -> density = mass / volume
  -> 根据密度阈值修正煤块/矸石分类

上位机
  -> 接收视觉端识别结果
  -> 管理相机/传感器/机械臂通信
  -> 根据置信度、密度和坐标生成分拣决策
  -> 向机械臂下发动作指令
  -> 在操作界面显示实时画面、检测结果、设备状态和日志
```

## 系统架构

完整系统由视觉端、上位机、机械臂、双目相机和重力传感器组成。

| 模块 | 职责 | 当前状态 |
|---|---|---|
| 视觉识别端 | 图像采集、YOLO 检测、bbox/class/conf 输出、深度点云与体积估算 | 训练、预测和体积估算实验已有代码 |
| 上位机 | 操作界面、视觉端通信、机械臂通信、传感器数据融合、分拣决策、状态管理 | 已有接口契约和功能边界设计，完整工程待集成 |
| 双目相机 | 提供 RGB 图像和深度图，用于目标检测、三维定位和体积估算 | 以 Intel RealSense D435i 为目标硬件 |
| 重力传感器 | 提供目标质量，用于和体积结合计算密度 | 待接入 |
| 机械臂 | 根据上位机下发的坐标和动作指令完成抓取、搬运、分拣 | 待联调 |

上位机在系统中处于调度中心位置，不直接训练模型，而是负责把视觉识别结果转化为可执行的设备动作。典型数据流如下：

```text
视觉端 -> 上位机：目标类别、置信度、检测框、三维坐标、深度有效性
重力传感器 -> 上位机：质量数据
上位机 -> 机械臂：抓取坐标、目标类别、动作指令
上位机界面 -> 操作员：实时画面、检测框、设备状态、报警信息、运行日志
```

## 上位机功能规划

上位机是本项目后续工程化落地的核心模块，计划包含以下功能：

- 视觉端通信：通过 TCP 长连接接收视觉端发送的 NDJSON 检测结果，并进行字段校验、心跳检测和异常处理
- 摄像头/视频显示：显示 RealSense 或 RTSP 视频流，并叠加检测框、类别、置信度和三维坐标
- 机械臂通信：根据分拣结果向机械臂控制器发送抓取点位、动作类型和执行状态查询指令
- 重力传感器接入：读取目标质量，与视觉端估算体积结合计算密度
- 分拣决策：高置信度目标直接按 YOLO 分类处理，低置信度目标进入体积/密度复核流程
- 坐标转换：将相机坐标或皮带坐标转换为机械臂坐标，支持现场标定参数加载
- 操作界面：提供启动、暂停、复位、手动抓取、阈值配置、设备状态监控和日志查看
- 运行记录：保存识别结果、低置信度复核结果、机械臂动作记录和异常事件

## 环境依赖

建议使用 Python 3.9+，并根据是否使用深度相机安装对应依赖。

基础训练/推理：

```bash
pip install ultralytics opencv-python numpy
```

D435i 体积估算实验：

```bash
pip install open3d pyrealsense2
```

如果需要 GPU 训练，请按本机 CUDA 版本安装匹配的 PyTorch。

## 使用方法

### 1. 训练检测模型

训练配置集中在 `main.py` 的 `TRAIN_ARGS` 中，默认使用：

- model: `yolo26n.pt`
- data: `DATASET/data.yaml`
- epochs: `100`
- imgsz: `640`
- batch: `16`
- output: `runs/coal_yolo26n_aug`

运行：

```bash
python main.py
```

训练结束后会输出关键指标，并生成：

```text
runs/coal_yolo26n_aug/metrics_summary.md
```

### 2. 单图预测

`test.py` 当前使用 `runs/coal_v1/weights/best.pt` 对一张训练集图片进行预测，结果保存到 `runs/predict_v1`。

```bash
python test.py
```

如需预测其他图片或使用其他权重，修改 `test.py` 中的：

```python
YOLO(r"D:\Vision_coal_gangue\runs\coal_v1\weights\best.pt")
source=r"D:\Vision_coal_gangue\DATASET\train\images\..."
```

### 3. D435i 体积估算实验

体积估算脚本位于 `camera_volume/test_volum.py`，流程为：

1. 采集空传送带/桌面的深度点云
2. 使用 RANSAC 拟合底面平面
3. 放入单个煤块或矸石并再次采集
4. 提取高出底面的物体点云
5. 使用高度积分法估算体积

运行：

```bash
cd camera_volume
python test_volum.py
```

脚本会生成：

```text
empty_plane_cloud.ply
scene_with_object_cloud.ply
object_only_cloud.ply
```

并输出估算体积，单位包括 `m^3`、`cm^3` 和 `L`。

## 接口协议

`tech-document.md` 定义了视觉端与上位机之间的接口契约。上位机作为视觉结果的接收方，同时也是机械臂和传感器的调度方：

- 协议版本：`1.1`
- 传输方式：TCP 长连接
- 数据格式：UTF-8 NDJSON，每行一个 JSON 对象
- 默认端口：`9001`
- 坐标输出：皮带坐标系下的 3D 点，单位 mm
- 深度相机：Intel RealSense D435i

典型输出对象包含：

```json
{
  "class_name": "gangue",
  "confidence": 0.86,
  "bbox": [320, 180, 80, 60],
  "center_pixel": [360, 210],
  "world_coord_mm": [125.4, 68.2, 42.5],
  "depth_valid": true
}
```

完整字段、坐标系约定、心跳、异常处理和联调路线请见 `tech-document.md`。
